# Docly

All your health records in one place: visits, prescriptions, tests and medications for you and your family.

Static web app with a Supabase backend. Works on phones (mobile layout) and desktop (sidebar layout).

See [SETUP.md](SETUP.md) to connect Supabase and publish on GitHub Pages.

## Versions
